# What is Infrastructure as Code and Why It's Transforming DevOps

Traditionally, configurations of servers would be done manually by system administrators,
which could be very hectic, time-consuming, prone to errors and inconsistency across different platforms.
To tackle the challenges, here comes an introduction of Infrastructure As Code, IaC, which involves provisioning and managing infrastructures like servers,
databases, and networks using code.
IaC gives improvement of the services by allowing automation, repetition of processes and by allowing version-control.

# The difference between declarative and imperative approaches
# Declarative Approach
Involved defining the desired state of infrastructure you would want to work on.

Terraform uses this approach.

# Imperative approach
It defines step-by-step on how to achieve a given tasks using available resources.

Scripting languages uses this approach.

# Why Terraform is worth learning
Terraform is the most widely IaC tool used across different cloud platforms.
Terraform can allow you to define infrastructure once and deploy it across multiple cloud platforms available.
